# Люди великой страны

Одностраничный информационный сайт (лендинг-визитка) «Люди великой страны» —
о национальных традициях народов России, семейных ценностях, профессиях
и человеческом подвиге. Каждый раздел проиллюстрирован фотографиями,
а мини-викторина «Знаешь ли ты?» в конце помогает закрепить материал.
Страница адаптивная (от 320 px до 1440+ px), доступная и полностью автономная:
все ресурсы лежат внутри проекта.

## Разделы страницы

- **Традиции** — Масленица, Сабантуй, Навруз, Ысыах, Сурхарбан, Шагаал (Цаган Сар)
- **Семейные ценности** — уважение к старшим, дом как семейный очаг, любовь и верность
- **Профессии** — врач, учитель, строитель, агроном, пожарный-спасатель, машинист
- **Подвиг** — защитники Отечества, первые полёты в космос, повседневные герои
- **Викторина** — шесть вопросов по материалам страницы с проверкой ответов

## Запуск

Особых действий не требуется: сайт полностью статический и работает без
сборки. Откройте `index.html` двойным щелчком в любом современном браузере
(Chrome, Firefox, Edge).

## Особенности

- Только клиентские технологии: HTML5, CSS3, ванильный JavaScript (ES6+) —
  без внешних CDN, шрифтов и библиотек.
- Семантические теги: `<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`.
- Все изображения имеют атрибут `alt`; есть «скип-ссылка» на содержимое
  и якорная навигация по разделам.
- Поддержка клавиатурной навигации и режима `prefers-reduced-motion`.
- Единая тёплая светлая палитра: бумажный фон, тёмно-красный и золотой.
